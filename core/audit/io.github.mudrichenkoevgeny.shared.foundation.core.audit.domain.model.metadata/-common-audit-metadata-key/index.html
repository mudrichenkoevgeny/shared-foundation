CommonAuditMetadataKey

enum class CommonAuditMetadataKey : AuditMetadataKey, Enum<CommonAuditMetadataKey>

Cross-cutting audit metadata keys for AuditEventMetadata.

The first keys follow the field order of ClientDeviceInfo then ClientInfo (deviceId … apiVersion), then diagnostic keys, then DENIED_REASON, ERROR_ID, and ERROR_CODE last.
