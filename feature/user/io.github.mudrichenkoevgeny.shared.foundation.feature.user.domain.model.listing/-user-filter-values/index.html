UserFilterValues

object UserFilterValues

Stable keys for filtering user collection list endpoints.

Keys follow the declaration order of properties in UserPrivate. Use these constants when building HTTP query strings, parsing list requests, or mapping filters in services and persistence so clients, servers, and documentation stay aligned.
