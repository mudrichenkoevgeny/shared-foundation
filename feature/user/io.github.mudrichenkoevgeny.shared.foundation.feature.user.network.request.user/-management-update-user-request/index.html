data class ManagementUpdateUserRequest(val accountStatus: PatchField = PatchField.Unchanged, val authorityLevel: PatchField = PatchField.Unchanged, val permissionCodes: PatchField = PatchField.Unchanged, val lockoutType: PatchField = PatchField.Unchanged, val temporaryLockoutUntil: PatchField = PatchField.Unchanged, val storageConfiguration: PatchField = PatchField.Unchanged, val nickname: PatchField = PatchField.Unchanged, val displayName: PatchField = PatchField.Unchanged, val avatarFileId: PatchField = PatchField.Unchanged, val birthdate: PatchField = PatchField.Unchanged)

Request body for administrative updates to a target user's account, status, permissions, and details (management API).

Uses 3-state PatchField properties:

  • PatchField.Unchanged: Field omitted in request; leave unchanged in persistence.

  • PatchField.Value with non-null value: Set field to new value in persistence.

  • PatchField.Value with null value: Explicitly clear/nullify field in persistence.
