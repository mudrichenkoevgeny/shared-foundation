# TypeScript & NPM Package Generation Standard

This document defines the generation rules, export contracts, and Web consumer integration patterns for the `@mudrichenkoevgeny/shared-foundation` NPM package (`build/npm-package/`).

## 1. Package Purpose & Target Consumers

The `@mudrichenkoevgeny/shared-foundation` NPM package provides a **Single Source of Truth (SSOT)** between Kotlin Multiplatform backend/client services and TypeScript/React web applications (e.g. `web-platform-sdk`).

It exports:
1. **Zod Validation Schemas (`*Schema`)**: Auto-generated validation schemas for all Request payloads, Response DTOs, and Navigation Screen Parameters.
2. **TypeScript Interfaces & Types**: Typed models for all DTOs (`UserSummaryPayload`), Domain Models (`UserSummary`), and Screen Parameters (`ManagementUserListParams`).
3. **Runtime Enums**: TS types and runtime JS objects for all domain enums and string unions using wire `.value` representations.
4. **Route Constants**: Strongly typed REST API routes (`ManagementUsersRoutes`, `OpenLoginRoutes`, etc.) and Navigation Screen routes (`ManagementUsersNavigation`, `ClientAuthNavigation`, etc.).
5. **Machine-Readable Codes**: String constants for error codes (`CommonErrorCodes`, `UserErrorCodes`) and permission strings (`UserPermissionCode`).
6. **Branded Domain Identifiers**: Type-safe domain IDs (`UserId`, `UserSessionId`, `UserIdentifierId`, `AuditEventId`, `ClientDeviceId`) with converter functions (`toUserIdOrThrow`, `toUserIdOrNull`).
7. **Runtime Domain Mappers**: Pure JS mapping functions (`toAuditEventSummary`, `toUserPrivatePayload`, etc.).

## 2. Generator Rules (`tools/npm-generator`)

The package is generated by `NpmGenerator.kt` triggered via `./gradlew generateNpmPackage`.

### 2.1. Versioning
- The `version` property in generated `package.json` dynamically inherits the project version from root `build.gradle.kts` via system property `PACKAGE_VERSION`.

### 2.2. Declaration Order (Preventing Temporal Dead Zone in ESM)
- **Top-Level Enums First:** In `index.mjs` / `index.js`, all enum Zod schemas (`loginStepSchema`, `totpStepSchema`, `unlockMethodSchema`, `userRoleSchema`, etc.) MUST be exported at the top of the file (right after branded types and before any DTO schema or mapper).
- This prevents `ReferenceError` during ESM module evaluation when a DTO schema or parameter schema references an enum schema.

### 2.3. Default Values & Optional Field Handling
- Parameters in Kotlin primary constructors with default values (`param.isOptional == true`) MUST be generated as optional fields in Zod schemas and TypeScript interfaces:
  - **Arrays (`List<T>`)**: Appended with `.default([])`.
  - **Pagination (`pageNumber`, `pageSize`)**: Appended with `.default(ListingDefaultValues.PAGE_NUMBER)` / `.default(ListingDefaultValues.PAGE_SIZE)`.
  - **Nullable fields**: Appended with `.default(null)`.
  - **Other fields**: Appended with `.optional()`.
  - **TypeScript `index.d.ts`**: Generated with `?` (e.g., `pageNumber?: number;`, `actorIds?: string[];`).

### 2.4. Mandatory JSDoc Code Documentation
- All exported interfaces, types, object constants, properties, enum entries, and mapper functions in `index.d.ts` MUST contain JSDoc documentation (`/** ... */`) extracted directly from Kotlin source KDocs via `extractKDoc`.
- AI agents MUST NEVER delete or omit JSDoc extraction logic when updating `NpmGenerator.kt`.

## 3. Web SDK Consumer Guidelines

1. **REST API Endpoint Requests:**
   - Network layer classes strictly use REST API route constants (e.g. `ManagementAuditRoutes.GET_AUDIT_EVENTS`).
   - Use `appendQueryParamsToPath(route, params)` to format path and query strings.

2. **Router & Deep Link Parsing:**
   - Use `*ParamsParser.parse(rawSearch)` for crash-proof deep link query parameter parsing.
   - Use `params.toQueryMap()` to write clean URL search maps back to the browser address bar (omitting default values).

3. **Smart Back-Navigation:**
   - Use `PARENT_ROUTE` constants on Navigation objects (e.g. `ManagementAuditNavigation.AuditEventList.PARENT_ROUTE`) for fallback backstack targets.
